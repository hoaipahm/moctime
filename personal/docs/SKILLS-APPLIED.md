# Skills applied to this build

Used relevant skills rather than loading unrelated language/framework instructions:

- dev-workflow-orchestrator: requirements → architecture → implementation → verification.
- communication-and-reporting, requirement-clarification, idea-to-requirements, project-planning: user scope and Android APK confirmation.
- impeccable: supplied screenshot as pinned visual authority, responsive implementation, rendered captures and independent finish review.
- anti-hallucination-guardrails, project-analysis, environment-setup, tech-stack-and-architecture: inspected empty workspace and actual installed tools; official Android compatibility documentation.
- dependency-management: verified npm packages, lockfile, audit; no cloud or AI service added.
- implementation-workflow, clean-code-standards, javascript-typescript-best-practices, frontend-ui-quality: typed shared UI, localization, tokens, accessible dialogs and forms.
- security-checklist, error-handling-resilience, async-concurrency-correctness, edge-case-analysis: strict import validation, atomic restore, media bounds, regex worker timeout, device permission denial handling.
- java-best-practices, shell-scripting-safety: Android WebView shell, restricted asset/file access, document exports, repeatable APK build with validated build-local cleanup.
- testing-strategy, code-verification, code-quality-gate, code-review: real unit/browser/build/signature checks; do not replace phone testing with browser claims.
- documentation-and-summary, release-and-deployment: APK handoff, backups, setup and explicit evidence boundaries.

`sites` was consulted but hosted-site publication is not used: this task ships a local Android application and browser companion. Plugin-managed skills requiring ChatGPT-only services are not copied into the mobile application. Applying a skill does not install its external services into the product.

## Asset provenance

QA PNG files are actual browser screenshots, not mockups or generated product evidence. Nunito Sans is self-hosted from @fontsource/nunito-sans under OFL; lucide icons are from lucide-react under ISC.
